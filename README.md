# Tenis Tami Řeporyje — návrhy nového webu

**Náhled:** https://petrluxa.github.io/Reporyje-Tami/

Dva návrhy úvodní stránky nového webu tenistami-reporyje.cz. Obsah je stejný, liší se náladou
a tím, jak ukazují obsazenost dvorců:

- **01 Antracit** — tmavá, odklápěcí tabule volných hodin
- **02 Antuka** — světlá moderní, den na dvorcích s cenovou páskou

Texty, ceny a fotky pocházejí ze současného webu. Obsazenost dvorců je ukázková.
